# Spirit Island – Spirits (Offline-Kopie)

Inoffizielle, nicht-kommerzielle Offline-Kopie der Spirit-Seiten des [Spirit Island Wiki](https://spiritislandwiki.com/),
Stand April 2025, gesichert über das [Internet Archive](https://web.archive.org/web/20250427153313/https://spiritislandwiki.com/index.php?title=List_of_Spirits).

**Online ansehen:** https://mawille.github.io/spirit-island/

**Offline nutzen:** Repository herunterladen (Code → Download ZIP) und `index.html` im Browser öffnen.

## Inhalt

- `index.html` – Liste aller Spirits (sortierbar)
- `<Spirit>.html` – je Spirit eine Seite mit allen Reitern (Spirit Board, Lore, Unique Power Cards, Strategy, Aspects …)
- `images/` – alle verwendeten Bilder lokal
- `css/`, `js/` – Wiki-Stylesheets und ein kleines Skript für Reiter und Sortierung (ersetzt die Wiki-Skripte)
- `tools/build.py` – Skript, mit dem die Kopie aus dem Internet Archive erzeugt wurde

Links auf andere Wiki-Seiten (z. B. einzelne Power Cards, Adversaries) und eingebettete Videos führen weiterhin ins Internet.
